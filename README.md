# 🎮 GameReviewBot

> Telegram-бот, который собирает обзор игры из **Steam** и **OpenCritic**, делает ИИ-выжимку отзывов и выдаёт вердикт: **брать или подождать**.

![Node.js](https://img.shields.io/badge/Node.js-18%2B-43853d)
![Telegraf](https://img.shields.io/badge/Telegraf-4.x-26A5E4)
![License](https://img.shields.io/badge/license-MIT-blue)

Пишешь боту `/review Elden Ring` — получаешь структурированный обзор с рейтингами, ценой, разбором «что хвалят / что ругают» и итоговым вердиктом.

---

## ✨ Возможности

- 🟦 **Steam** — процент положительных отзывов, их количество, цена и скидка
- 🟩 **OpenCritic** — оценка критиков и процент рекомендующих (парсинг страницы через `cheerio`)
- 🤖 **ИИ-выжимка отзывов** — что хвалят и что ругают, на основе реальных отзывов Steam. Работает с любым OpenAI-совместимым провайдером, в том числе **бесплатными** (Groq, Gemini, Ollama)
- 🎯 **Вердикт** — 🟢 Смело покупай · ✅ Стоит брать · 🟡 Лучше подождать скидку · 🔴 Лучше мимо
- 💬 Красивый ответ в Markdown с таблицей и эмодзи
- 🛟 Аккуратная обработка ошибок: игра не найдена, нет данных из источника, сбой ИИ — бот не падает

## 🚀 Быстрый старт

```bash
git clone https://github.com/sonik-boom71/GameReviewBot.git
cd GameReviewBot
npm install

# создай .env из примера и впиши ключи
cp .env.example .env

npm start
```

Нужен **Node.js 18+**. После запуска открой Telegram и напиши боту `/start`.

## 🔑 Где взять ключи (всё бесплатно)

| Ключ | Где получить | Обязателен? |
|------|--------------|-------------|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` | ✅ Да |
| `STEAM_API_KEY` | [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) | ⬜ Нет¹ |
| `OPENAI_API_KEY` + `OPENAI_BASE_URL` | Groq / Gemini / Ollama — см. ниже | ⬜ Нет² |
| `OPENCRITIC_RAPIDAPI_KEY` | [RapidAPI OpenCritic](https://rapidapi.com/opencritic-opencritic-default/api/opencritic-api) | ⬜ Нет³ |

> ¹ Цена и отзывы Steam тянутся через публичные store-эндпоинты — ключ не требуется, но оставлен для будущих официальных вызовов.
> ² Без ИИ-ключа бот делает выжимку из реальных цитат отзывов. С ключом — осмысленную выжимку (бесплатно через Groq/Gemini).
> ³ Нужен только если поисковая выдача на твоём сервере режется и OpenCritic стабильно показывает «нет данных».

### 🤖 Бесплатный ИИ за 2 минуты (Groq)

1. Зарегистрируйся на [console.groq.com/keys](https://console.groq.com/keys) и создай ключ `gsk_...`
2. Впиши в `.env`:
   ```env
   OPENAI_BASE_URL=https://api.groq.com/openai/v1
   OPENAI_API_KEY=gsk_твой_ключ
   OPENAI_MODEL=llama-3.3-70b-versatile
   ```
3. Перезапусти бота. Готово — выжимку теперь пишет ИИ.

Альтернативы тем же способом: **Google Gemini** (`gemini-2.0-flash`, самый большой бесплатный лимит) и **Ollama** (локально, без интернета и ключей). Готовые примеры — в [`.env.example`](.env.example).

## ⚙️ Переменные окружения

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `BOT_TOKEN` | Токен Telegram-бота | — |
| `STEAM_CC` | Регион/валюта цен (`us`, `ru`, `eu`, `ua`, `kz`, `tr`…) | `us` |
| `OPENAI_BASE_URL` | Базовый URL OpenAI-совместимого провайдера | пусто (= OpenAI) |
| `OPENAI_API_KEY` | Ключ ИИ-провайдера | пусто |
| `OPENAI_MODEL` | Модель | `gpt-4o-mini` |
| `OPENCRITIC_RAPIDAPI_KEY` | Ключ RapidAPI для OpenCritic | пусто |

## ❓ FAQ

<details>
<summary><b>Это правда бесплатно?</b></summary>

Да. Данные Steam и OpenCritic берутся без оплаты. Для ИИ-выжимки есть бесплатные провайдеры (Groq, Google Gemini) или локальный Ollama. Платный OpenAI — лишь один из вариантов, не обязательный.
</details>

<details>
<summary><b>Обязательно ли подключать ИИ?</b></summary>

Нет. Без ИИ-ключа бот всё равно работает и показывает выжимку из реальных цитат отзывов. С любым OpenAI-совместимым ключом блоки «что хвалят / что ругают / вердикт» становятся осмысленными.
</details>

<details>
<summary><b>Почему OpenCritic иногда пишет «нет данных»?</b></summary>

OpenCritic закрыл бесплатный публичный API (теперь он платный через RapidAPI), а их сайт — SPA, где поиск рендерится в браузере. Бот находит страницу игры через поисковики и парсит её через `cheerio` (страницы игр отдаются сервером уже готовыми). На некоторых IP/серверах поисковая выдача режется антиботом — тогда добавь бесплатный `OPENCRITIC_RAPIDAPI_KEY`, и оценки будут тянуться стабильно. Steam-часть от этого не зависит и работает всегда.
</details>

<details>
<summary><b>Бот находит не ту игру (например, «Hades» → «Hades II»)</b></summary>

Берётся первый результат поиска Steam. Уточни запрос: пиши полное название, лучше на английском (`/review Hades 2020` или конкретнее).
</details>

<details>
<summary><b>Как сменить валюту и регион цен?</b></summary>

Поставь `STEAM_CC` в `.env` (например, `ru`, `eu`, `ua`, `kz`, `tr`). Цена и валюта отобразятся для этого региона.
</details>

<details>
<summary><b>Бот не отвечает / ошибка <code>409 Conflict</code></b></summary>

Так бывает, если запущено сразу два экземпляра бота с одним токеном (Telegram разрешает только один long-polling). Останови лишние процессы Node и запусти один.
</details>

<details>
<summary><b>Какую ИИ-модель выбрать?</b></summary>

На Groq: <code>llama-3.3-70b-versatile</code> — качественнее, <code>llama-3.1-8b-instant</code> — быстрее. На Gemini: <code>gemini-2.0-flash</code>. Меняется одной строкой <code>OPENAI_MODEL</code> в <code>.env</code>.
</details>

<details>
<summary><b>Можно держать бота 24/7?</b></summary>

Да. Подойдёт любой VPS или бесплатные хостинги вроде Railway / Render / Fly.io. Нужен Node 18+ и те же переменные окружения. Для продакшена можно завернуть запуск в <code>pm2</code> или systemd.
</details>

<details>
<summary><b>Безопасно ли хранить ключи?</b></summary>

Все ключи лежат в <code>.env</code>, который добавлен в <code>.gitignore</code> и не попадает в git. Не коммить его и не выкладывай. Если ключ где-то засветился — отзови и пересоздай его в кабинете провайдера.
</details>

## 🗂 Структура проекта

```
GameReviewBot/
├── index.js            # точка входа: команды бота, оркестрация, обработка ошибок
├── steamApi.js         # поиск игры, цена/скидка, сводка и выборка отзывов

└── package.json
```
