# 🎮 GameReviewBot

> Telegram-бот, который собирает обзор игры из **Steam** и **OpenCritic**, делает ИИ-выжимку отзывов и выдаёт вердикт: **брать или подождать**.

![Node.js](https://img.shields.io/badge/Node.js-18%2B-43853d)
![Telegraf](https://img.shields.io/badge/Telegraf-4.x-26A5E4)
![License](https://img.shields.io/badge/license-MIT-blue)

Пишешь боту `/review Elden Ring` — получаешь структурированный обзор с рейтингами, ценой, разбором «что хвалят / что ругают» и итоговым вердиктом.

---

## ✨ Возможности

- 🟦 **Steam** — процент положительных отзывов, их количество, цена и скидка
- 🟩 **OpenCritic** — оценка критиков и процент рекомендующих (парсинг страницы через `cheerio`)
- 🤖 **ИИ-выжимка отзывов** — что хвалят и что ругают, на основе реальных отзывов Steam. Работает с любым OpenAI-совместимым провайдером, в том числе **бесплатными** (Groq, Gemini, Ollama)
- 🎯 **Вердикт** — 🟢 Смело покупай · ✅ Стоит брать · 🟡 Лучше подождать скидку · 🔴 Лучше мимо
- 💬 Красивый ответ в Markdown с таблицей и эмодзи
- 🛟 Аккуратная обработка ошибок: игра не найдена, нет данных из источника, сбой ИИ — бот не падает

---
